# Grove Project Starter

This is the first clean project repo created from `grove-kernel`.

Its purpose is to serve as a fully isolated starter instance for a new project.

## Rules

- no inherited business context from `business-os`
- no inherited runtime state from `.paperclip/instances/default`
- no reused secrets
- all durable project context lives in local files

This repo is paired with the Paperclip instance skeleton at:
