## SOP-001: Inbound Ticket Handling

1. Read the full ticket before responding
2. Check if a known resolution exists in `faq.md`
3. If yes: respond with the answer, mark ticket resolved
4. If no: classify the issue type using `escalation-matrix.md`
5. Escalate or resolve based on classification

## SOP-002: Escalation

1. Identify the escalation target from `escalation-matrix.md`
2. Create a subtask in Paperclip assigned to the correct agent/team
3. Include: ticket ID, issue summary, steps already taken
4. Notify the customer that their issue has been escalated
5. Set expected response time based on priority tier

## SOP-003: KPI Reporting

1. At the end of each week, compile: ticket volume, avg resolution time, escalation rate, CSAT
2. Post a summary comment on the CTO's active support tracking issue
3. Flag any metric outside target range

## SOP-004: Knowledge Base Updates

1. When a new issue is resolved that isn't in `faq.md`, add it
2. When an SOP changes, update this file with the new version and date
3. Notify CTO of any material changes to escalation routing
