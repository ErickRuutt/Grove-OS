# Value Propositions

## Purpose
Translate Grove positioning into role-specific value claims tied to measurable business impact.

## Scope
Messaging for ads, website modules, outbound sequences, and sales collateral.

## Inputs
- [positioning](./positioning.md)
- Sales and CS evidence of pain/cost patterns
- Activation and retention outcomes by segment
- [quality bar](../../_shared/02-quality-bar.md)

## Decision Rules
- Every value proposition must pair a pain statement with a measurable operational outcome.
- Prioritize operator, team lead, and founder messages over generic innovation language.
- Use one primary value prop per asset; avoid stacking multiple weak promises.

## Examples
- Operator: "Reduce execution drift by centralizing how teams run AI-enabled workflows."
- Team lead: "Give every function the same playbook memory so quality does not depend on who is online."
- Founder/CEO: "Turn AI adoption from scattered experiments into accountable operating leverage."

## Failure Modes
- Benefits with no implied metric (time, cost, consistency, conversion, retention).
- Claims that require future roadmap features to be true.
- Same value prop repeated unchanged across all roles/channels.
