# Sales QA Rubric

## Purpose
Define how to score sales artifacts and live execution quality for consistency and improvement.

## Scope
Used to assess calls, emails, and playbook adherence across the Sales pod.

## Inputs
- Call transcripts or notes
- Follow-up messages
- Opportunity stage progression outcomes

## Decision Rules
- Score each category 1-5: clarity, qualification rigor, objection handling, next-step control, and differentiation.
- A pass requires average score >= 4.0 with no category below 3.
- Any score below 3 requires a corrective action note.

## Examples
- Score 5 differentiation: Rep clearly framed Grove as business-memory + execution system, not chatbot novelty.
- Score 2 next-step control: Call ended without owner/date.

## Failure Modes
- Inflated scoring without evidence.
- Rubric use only for review, not coaching.
- Inconsistent scoring definitions across managers.
